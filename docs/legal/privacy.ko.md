# 개인정보 처리방침

EasyConvert 운영자는 「개인정보 보호법」 제30조에 따라 정보주체의 개인정보를 보호하고 관련 고충을 신속하게 처리하기 위하여 다음과 같이 개인정보 처리방침을 수립·공개합니다. 유럽연합의 이용자에게는 「일반 개인정보 보호규정」(GDPR)도 적용됩니다.

EasyConvert 운영자 정동인(이하 "운영자", support@aquilaxk.site)이 이 처리방침에 적은 개인정보의 개인정보처리자입니다.

## 1. 개인정보의 처리 목적

운영자는 다음 목적으로만 개인정보를 처리합니다.

- **파일 변환.** 이용자가 보낸 파일이나 링크를 받아 변환하고 결과를 전달합니다.
- **계정과 API 키 운영.** 계정을 만들고 보호하며, 로그인과 API 키·웹훅 관리를 제공합니다.
- **무료 이용 한도 적용과 서비스 보호.** 하루 변환 횟수를 세고, 짧은 시간의 과도한 요청을 제한하며, 악용을 찾아 막습니다.
- **문의 응대.** 문의, 신고, 권리 행사 요청에 답합니다.

앞의 두 목적은 이용자와의 계약을 이행하기 위하여 필요한 처리(「개인정보 보호법」 제15조제1항제4호, GDPR 제6조제1항(b))이며, 셋째 목적은 무료 서비스를 안전하게 유지하기 위한 운영자의 정당한 이익(같은 법 제15조제1항제6호, GDPR 제6조제1항(f))에 따른 처리입니다. 권한 있는 기관의 요청에 답하는 것은 법령상 의무를 지키기 위한 처리(같은 법 제15조제1항제2호, GDPR 제6조제1항(c))입니다. 운영자는 광고나 프로파일링을 위하여 개인정보를 처리하지 않습니다.

이용자에게 개인정보 제공을 요구하는 법령은 없습니다. 서버에서 변환하려면 파일이 필요합니다. 계정을 만들려면 이메일 주소와 비밀번호 또는 Google 로그인이 필요하며, 이것 없이는 계정 이용 계약을 맺을 수 없습니다. 계정이 없어도 무료 이용 한도 안에서 EasyConvert를 이용할 수 있습니다.

## 2. 처리하는 개인정보의 항목

브라우저가 지원하는 변환은 이용자의 기기에서 실행되며, 그 파일은 업로드되지 않고 운영자는 그 변환에 관하여 아무것도 받지 않습니다. 아래 표는 운영자의 서버에 도달하는 정보입니다.

| 구분 | 항목 | 수집 시점 |
| --- | --- | --- |
| 파일 | 업로드한 파일, 가져온 링크와 캡처한 웹페이지, 선택한 옵션, 변환 결과 | 서버에서 변환할 때 |
| 변환 작업 | 작업 ID, 파일 이름, 형식, 파일 크기, 선택한 옵션(비밀번호는 암호화), 웹훅 URL과 서명 비밀값, 이용자의 계정 또는 계정이 없으면 IP 주소(IPv6는 /64 네트워크), 상태, 시각, 진행 기록, 결과의 링크·크기·유형, 실패 사유 | 서버의 대기열에 변환을 넣을 때 |

| 이용 한도와 요청 횟수 기록 | 이용자의 계정 또는 계정이 없으면 IP 주소(IPv6는 /64 네트워크), 횟수 | 변환하거나 API를 호출할 때 |
| 계정 | 이메일 주소, 표시 이름, 비밀번호 해시, 로그인 방식, 요금제, 동의한 약관 버전, 생성·수정 시각, 변환 횟수 | 계정을 만들 때 |
| Google 로그인 | Google에서 받은 이름, 이메일 주소, 프로필 사진 | Google로 로그인한 경우에만 |
| API 키 | 키 이름, 키 접두어와 해시, 권한 범위, 허용 IP 주소, 웹훅 URL과 암호화된 서명 비밀값, 동의한 약관 버전, 만료일, 마지막 사용 시각, 일별 사용량 | API 키를 만들 때 |
| 실패한 웹훅 전송 | 대상 URL, 이벤트, 메시지(작업 ID, 파일 이름, 결과 링크, 실패 내용), 암호화된 서명 비밀값, 상태와 오류, 시각 | 이용자의 웹훅으로 보내지 못했을 때 |
| 문의 | 이메일 주소와 문의 내용 | support@aquilaxk.site로 메일을 보낼 때 |

이용자의 파일에는 이용자나 다른 사람의 개인정보가 들어 있을 수 있습니다. 운영자는 그 내용을 변환하기 위하여 기계로만 처리하며, 내용을 읽거나 분석하지 않고 변환 결과보다 오래 보관하지 않습니다.

운영자는 민감정보와 고유식별정보를 요구하지 않습니다. 개인정보를 판매하지 않으며, 이용자의 파일을 어떤 모델의 학습에도 이용하지 않습니다.

## 3. 개인정보의 처리 및 보유 기간

| 개인정보 | 보유 기간 |
| --- | --- |
| 업로드한 파일 | 그 파일을 읽는 마지막 변환이 끝나고 10분 뒤 삭제합니다. 어떤 변환에도 쓰이지 않은 파일은 길어도 1일 뒤 삭제합니다. |
| 변환 결과 | 처음으로 끝까지 내려받은 때부터 10분 뒤, 내려받지 않으면 만든 때부터 1시간 뒤 삭제합니다. 결과를 같은 응답으로 돌려주는 웹사이트 변환은 사본을 보관하지 않습니다. |
| 변환 중 임시 파일 | 변환을 시작하고 늦어도 2시간 뒤 삭제합니다. |
| 변환 작업(여러 단계로 된 작업 포함) | 작업이 끝나고 25시간 뒤 삭제합니다. 결과를 내려받을 수 있는 1시간과, 삭제된 결과를 내려받으려 할 때 삭제되었다고 알리는 1일을 합한 기간입니다. 작업과 함께 보낸 파일 내용과 웹훅 서명 비밀값은 작업이 끝날 때 삭제합니다. 백업에는 남아 있을 수 있으며, 그 내용은 아래 백업 항목에 적었습니다. |
| 실패 원인을 찾기 위한 실패 작업 사본 | 실패하고 25시간 뒤 삭제합니다. |
| 실패한 웹훅 전송 | 전송에 실패하고 30일 뒤 삭제하며, 대시보드에서 그 전에 삭제할 수 있습니다. |
| 계정의 파일 목록 항목 | 해당 파일과 함께 만료됩니다. |
| 하루 이용 횟수 기록 | 그날(UTC)이 끝날 때까지 |
| 짧은 시간 요청 횟수 기록 | 마지막 요청부터 1시간 |
| 업로드 한도 기록 | 2일 |
| 로그인 시도 제한 기록 | 5분 |
| 엣지 서버 로그 | 최대 15일. 로그는 매일 교체하며 이전 파일 14개를 보관합니다. |
| 계정, API 키, 사용량 | 계정 삭제를 요청할 때까지 |
| 계정과 변환 작업 기록의 백업 | 6시간마다 백업하여 같은 서버에만 보관하고 다른 곳에는 복사하지 않으며, 만든 때부터 늦어도 7일 뒤 삭제합니다. 백업에는 그 시점의 계정, API 키, 변환 작업 기록이 들어 있습니다. API로 파일을 요청 본문에 담아 보낸 작업은 작업이 끝날 때까지 그 파일을 기록에 두므로, 그런 작업이 실행되는 동안 만든 백업에는 백업을 삭제할 때까지, 길어도 7일 동안 그 파일이 남습니다. 업로드한 파일과 변환 결과는 백업하지 않습니다. |
| 문의 내용 | 운영자의 메일함에 보관하며, 요청하면 삭제합니다. |

이 기간은 이 페이지 맨 위 날짜에 적용되는 설정값입니다. 서버의 디스크가 가득 차면 변환 결과를 기간보다 먼저 삭제할 수 있습니다.

## 4. 개인정보의 파기 절차 및 방법

보유 기간이 끝나면 시스템이 파일이나 기록을 자동으로 삭제하며, 삭제한 정보는 시스템에서 복구할 수 없습니다. 다만 기록의 백업(3항)에 들어 있는 사본은 그 백업을 삭제할 때까지, 만든 때부터 길어도 7일 동안 남습니다. 운영자는 업로드한 파일과 변환 결과를 백업하지 않으며, 백업은 장애 뒤 서비스를 복원하는 데만 사용합니다.

계정 삭제를 요청하면 운영자는 요청이 그 계정의 이메일 주소에서 왔는지 확인합니다. 그런 다음 계정, API 키와 그 서명 비밀값, 변환 작업과 그 파일, 실패한 웹훅 전송, 사용량 기록을 각 기록을 지우는 도구로 삭제하고, 삭제를 마치면 알려 드립니다. 운영자는 확인된 요청을 받은 날부터 2일 이내에 계정을 삭제합니다. 백업에 들어 있는 계정의 사본은 그 뒤 7일 6시간 이내에 삭제되므로, 요청을 받은 날부터 10일 이내에 모두 삭제됩니다. 백업으로 서비스를 복원하는 경우 운영자는 그 백업을 만든 뒤에 삭제한 계정을 모두 다시 삭제합니다.

## 5. 개인정보의 제3자 제공

운영자는 개인정보를 제3자에게 제공하지 않습니다. 다만 영장 등 법령에 따라 응해야 하는 요청은 예외입니다.

## 6. 개인정보 처리업무의 위탁

운영자는 다음 수탁자에게 개인정보 처리업무를 위탁하며, 수탁자는 위탁받은 업무에만 개인정보를 처리합니다.

| 수탁자 | 위탁 업무 | 처리 위치 |
| --- | --- | --- |
| Oracle Corporation (Oracle Cloud Infrastructure) | 서버, 파일, 기록의 호스팅 | 대한민국 서울 |
| Cloudflare, Inc. | 웹사이트와 API의 전달 및 보호. 파일을 포함한 모든 요청이 이 네트워크를 거칩니다. support@aquilaxk.site로 보낸 메일을 보관하지 않고 운영자의 메일함으로 전달 | 세계 각지의 데이터센터(7항 참고) |

support@aquilaxk.site로 보낸 메일은 운영자 본인의 메일함에 도착하며, 운영자가 그곳에서 읽고 답합니다.

Google로 로그인하는 기능을 제공하고 이용자가 이를 이용하는 경우, Google LLC는 자신의 개인정보 처리방침에 따라 로그인을 처리하며 운영자의 수탁자가 아닙니다.

## 7. 개인정보의 국외 이전

Cloudflare는 이용자의 요청과 지원 주소로 보낸 메일을 이용자와 가장 가까운 데이터센터에서 처리하며, 그 데이터센터는 국외에 있을 수 있습니다.

- **이전되는 개인정보 항목.** 접속 정보, 파일을 포함한 요청 및 응답의 내용, support@aquilaxk.site로 보낸 메일
- **이전되는 국가.** Cloudflare 네트워크가 있는 국가. Cloudflare, Inc.의 본사는 미국에 있습니다.
- **이전 시기 및 방법.** 요청이나 메일마다 암호화된 연결(TLS)로 전송
- **이전받는 자.** Cloudflare, Inc., 101 Townsend St., San Francisco, CA 94107, USA, privacyquestions@cloudflare.com
- **이용 목적 및 보유·이용 기간.** 서비스의 전달과 보호, 메일 전달. 요청 정보는 Cloudflare의 고객 약관이 정한 기간 동안 보유하며, 전달하는 메일은 저장하지 않습니다.
- **거부 방법과 효과.** 이 네트워크 없이는 서비스를 이용할 수 없으므로, 국외 이전을 원하지 않으면 EasyConvert를 이용하지 않아야 합니다.

이 국외 이전은 이용자와의 계약 이행에 필요한 처리위탁으로서 이 처리방침에 공개한 경우(「개인정보 보호법」 제28조의8제1항제3호가목)에 해당합니다. 유럽연합의 이용자에 대해서는 대한민국에 대한 유럽연합 집행위원회의 적정성 결정이 대한민국의 운영자에게 개인정보를 이전하는 것에 적용됩니다. 미국과 그 밖의 국가에 있는 Cloudflare로 다시 이전하는 것은 유럽연합 표준계약조항을 포함한 Cloudflare의 고객 약관(GDPR 제46조제2항(c))에 따릅니다.

## 8. 개인정보의 안전성 확보 조치

- 모든 연결은 암호화(TLS)합니다.
- 비밀번호는 솔트를 더한 해시로만, API 키는 키를 사용한 해시로만 저장합니다. 웹훅 서명 비밀값은 키와 함께 저장할 때와 실패한 전송에 보관할 때 암호화합니다. 대기열의 변환은 함께 받은 비밀값을 작업이 끝날 때까지 가지고 있습니다.
- 외부 변환 프로그램은 네트워크에 접근할 수 없는 격리된 환경에서 실행합니다. 변환한 파일은 3항의 기간에 따라 삭제합니다.
- 서버에는 운영자만 접근할 수 있습니다.

모두 서비스 제공에 꼭 필요한 것이며, 광고나 분석용 쿠키는 사용하지 않습니다. 이용자는 브라우저 설정에서 쿠키와 사이트 데이터를 차단하거나 삭제할 수 있으며, 세션 쿠키가 없으면 로그인할 수 없습니다.
