# Benchmark corpus provenance

Every file here is generated by `bench/corpus/generate.ts` from standard command-line tools (ImageMagick `convert`,
ffmpeg with its bundled `flite` voice and `aevalsrc`/`mandelbrot` sources, and jszip), from libraries (pyarrow, openpyxl,
fontTools, through `generate-assets.py`), from calibre's `ebook-convert` and from text written for this project. No
third-party photographs, recordings, documents, tables or books are included, so nothing carries an external licence except
the font outlines (below): all other files are released under the repository licence (CC0 for the generated content).
`manifest.json` lists the SHA-256 of each file; `tests/bench-corpus.test.ts` checks the files against it and the
total against the 5 MB budget. Regenerate with `npx tsx bench/corpus/generate.ts` and commit the new manifest. Most files are a pure
function of the generator; the Parquet, XLSX, font and MOBI files are written by tools that stamp or reorder their output, so the
committed bytes are the record and the manifest pins them (`--only table,book,assets` regenerates just those, which needs
pyarrow, openpyxl, fontTools and calibre, and DejaVu Sans on the machine).

| File | Class | How it is made |
|---|---|---|
| `photo-a.jpg` | photo (JPEG, 768x512) | `convert -seed 7 plasma:fractal`, blurred, Gaussian noise added, JPEG quality 92 |
| `photo-b.png` | photo with a hard-edged subject (PNG, 640x432) | `plasma:fractal` seed 21 with a soft ellipse composited, noise added |
| `screenshot.png` | screenshot-like UI (PNG, 1024x640) | `convert -draw`/`-annotate` with DejaVu fonts (Bitstream Vera licence) |
| `lineart.png` | line art (PNG, 640x640) | anti-aliased circles, spokes and a polygon drawn with `convert -draw` |
| `clip.mp4` | short video (H.264, 320x240, 24 fps, 2 s, no audio) | ffmpeg `mandelbrot` source encoded with x264 at CRF 14 |
| `speech.wav` | speech (16 kHz mono PCM, 7.9 s) | ffmpeg `flite` filter (voice `slt`) reading a pangram text |
| `music.wav` | music (44.1 kHz stereo PCM, 4 s) | ffmpeg `aevalsrc` plucked-note chords (sums of decaying sines) |
| `scan.png` + `scan.gt.txt` | scanned page for OCR (grey PNG) | text of `scan.gt.txt` rendered with `convert`, rotated 0.6 degrees, blurred, noise added (a deliberately poor scan, 16 pt text) |
| `report.docx` + `report.gt.txt` | office document | built with jszip from the text of `report.gt.txt`: headings, paragraphs and a table, fixed timestamps |
| `data/records.jsonl` | compressible structured data | seeded generator (mulberry32) of 5000 JSON-lines log records |
| `data/table.jsonl` + `data/table.csv` | typed table, 2,500 rows, 9 columns (JSON lines; RFC 4180 CSV written from the same records) | seeded generator; commas, quotes and line breaks inside cells, digit strings with leading zeros, strings that read as exponents (`1e4`), empty cells, East Asian and Cyrillic text, emoji, ISO timestamps, booleans, floats |
| `data/table.parquet` | the table as Apache Parquet | pyarrow, Snappy, row groups of 1,000, timestamps as `timestamp[ms, UTC]` |
| `data/table.xlsx` | the table as a workbook | openpyxl write-only workbook, one sheet, fixed document properties |
| `fonts/sans.ttf` | text face with TrueType outlines and hinting, about 800 glyphs | DejaVu Sans subset (Basic Latin, Latin-1, Latin Extended-A, Greek, Cyrillic, punctuation) by fontTools; Bitstream Vera and DejaVu font licence (free redistribution and modification, the derivative may not be named "Bitstream" or "Vera") |
| `fonts/sans-cff.otf` | the same glyphs in a CFF-flavoured OpenType font | `sans.ttf` outlines drawn as exact cubic curves by fontTools (T2CharStringPen), no hinting; same licence |
| `ebooks/book.epub` | short book as EPUB 3 (10 chapters, a list, a table, a picture; 5,300 words) | jszip from the seeded prose of `generate-text.ts` (vocabulary written for this repository); the picture is `photo-a.jpg` scaled to 320 pixels |
| `ebooks/book.fb2` | the same book as FictionBook 2 | written by `generate-text.ts` |
| `ebooks/book.mobi` | the same book as MOBI 6 | `ebook-convert book.epub book.mobi --mobi-file-type=old` (calibre, GPL-3.0, run as a separate process; its output carries no calibre code) |
| `ebooks/book.gt.txt` | the text the book was written from | `generate-text.ts`: heading, paragraphs, list items and table rows, one block each |

The ground-truth texts (`scan.gt.txt`, `report.gt.txt`, `ebooks/book.gt.txt`) are original prose written for this repository. Synthetic
photographs are textures, not natural scenes; they exercise smooth gradients, noise and edges but understate the
detail of real photographs, so absolute numbers are for trend tracking rather than public comparison.
